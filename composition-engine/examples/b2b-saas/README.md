# B2B SaaS Reference Application

This application represents a fully end-to-end generated B2B SaaS system, composed deterministically using Minecode from its declarative description in `app.yaml`.

## Features Included

1.  **Authentication:** Fully functional Supabase auth routing handlers, user password authentication, mock password reset, and session control.
2.  **Multi-Tenant Organizations:** Workspaces/organizations tenant structures, user memberships, and email join invitations.
3.  **Role-Based Access Control (RBAC):** Roles, permissions, and roles listing endpoint.
4.  **Billing:** Stripe integration mappings (customers, subscriptions) and checkout/webhook API handlers.
5.  **Database Primitive:** Direct SQL DDL schemas and structured database migrations.

## Project Structure

This reference app showcases the outputs generated by the `@minecode/nextjs-supabase` adapter from the `app.yaml` blueprint. The adapter compiled the declarative features into a fully runnable Next.js App Router workspace on physical disk:

- `app/`: Next.js App Router source files (including backend API route handlers under `app/api/` and routes for login, rbac-admin, organizations and billing settings pages).
- `app/page.tsx`: Dynamically compiled index landing page providing quick visual routing links to every composed user page.
- `package.json`, `tsconfig.json`, `tailwind.config.ts`, `postcss.config.js`, `next.config.mjs`: Complete Next.js & Tailwind configuration files generated automatically.
- `generated/`: Central repository for compiled declarations (such as type definitions in `generated/types/database.ts`).
- `config/`: Central configurations and mappings (e.g., `config/permissions.ts` generated from security contracts).
- `supabase/migrations/`: Structured PostgreSQL DDL migration scripts corresponding to entity definition tables and builtin feature migration SQL scripts.

## How to Run & Deploy

Because this reference application has been composed and generated in **runnable mode** (meaning the adapter generated all standard workspace configuration and layout files directly alongside the artifacts), running and deploying this application is extremely simple:

### 1. Prerequisites

- **Node.js** (v20+)
- **pnpm** or **npm**
- **Supabase CLI** (for local database development and migrations)

### 2. Install Dependencies

Navigate directly to this directory and install the generated dependencies:

```bash
pnpm install
# or
npm install
```

### 3. Setup Local Database & Apply Migrations

Apply the generated schema migrations in order to initialize your Supabase/PostgreSQL database:

```bash
# Initialize local Supabase project (optional)
supabase init

# Start local Supabase development container or execute migrations directly inside your Postgres SQL editor
# Migrations are located under: supabase/migrations/
```

### 4. Configuration

Add your Supabase endpoint and credentials to your `.env.local` file:

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_project_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### 5. Run the Application Locally

Start the Next.js development server:

```bash
pnpm dev
# or
npm run dev
```

Open `http://localhost:3000` to interact with your fully functional Next.js/Supabase B2B SaaS application.
