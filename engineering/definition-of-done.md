# v0.1 Definition of Done

The v0.1 release is complete when:

- A valid application blueprint can be parsed and validated.
- Features can be discovered from a registry.
- Dependencies can be resolved deterministically.
- A composition plan can be generated.
- A Next.js/Supabase application can be generated.
- Built-in features provide production-quality foundations.
- MCP tools allow AI agents to drive the workflow.
- CLI tools allow human developers to drive the workflow.

General principles:
- Features describe capabilities, not files.
- Generated code is separated from extensions.
- Custom logic belongs in extension points.
- Built-in features require contracts, tests, docs, and migrations.
